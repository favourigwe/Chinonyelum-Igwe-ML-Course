# Module 07

## Overview

This lab focused on **model evaluation**, emphasizing why accuracy alone is not enough to measure the performance of a machine learning model. Using the Titanic dataset, I explored confusion matrices, precision, recall, F1-score, and cross-validation to gain a more complete understanding of model performance.

## Objectives

- Evaluate machine learning models beyond accuracy
- Generate and interpret a confusion matrix
- Calculate precision, recall, and F1-score
- Perform cross-validation
- Understand when different evaluation metrics are most appropriate

## Skills Practiced

- Python
- Scikit-learn
- Model Evaluation
- Confusion Matrix
- Precision
- Recall
- F1-Score
- Cross-Validation

## What I Learned

In this lab, I learned that accuracy does not always provide a complete picture of a model's performance. I practiced generating confusion matrices and classification reports to better understand prediction errors. I also learned how cross-validation provides a more reliable estimate of model performance by evaluating the model across multiple data splits instead of relying on a single train-test split.
