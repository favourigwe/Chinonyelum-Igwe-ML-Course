# Module 13

## Overview

This lab focused on **machine learning pipelines**, demonstrating how multiple preprocessing and modeling steps can be combined into a single, organized workflow. I learned how pipelines simplify model development, reduce repetitive code, and help ensure consistent preprocessing during both training and prediction.

## Objectives

- Understand the purpose of machine learning pipelines
- Build an end-to-end machine learning workflow
- Combine preprocessing and model training into a single pipeline
- Improve workflow organization and reproducibility

## Skills Practiced

## What I Learned

In this lab, I learned how machine learning pipelines make the development process more efficient by combining preprocessing steps and model training into one reusable workflow. Using pipelines helps prevent common mistakes, keeps code organized, and ensures that data is processed consistently throughout the machine learning lifecycle. This lab demonstrated the importance of building scalable and reproducible machine learning solutions.
