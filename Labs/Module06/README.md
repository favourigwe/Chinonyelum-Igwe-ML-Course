# Module 06

## Overview

This lab introduced **regression and classification**, two fundamental types of supervised machine learning. Using the Titanic dataset, I built and evaluated both a Linear Regression model and a Logistic Regression model to understand how different algorithms are used depending on the prediction task.

## Objectives

- Understand the difference between regression and classification
- Train a Linear Regression model
- Train a Logistic Regression model
- Evaluate model performance using appropriate metrics
- Interpret machine learning results

## Skills Practiced

- Python
- Pandas
- Scikit-learn
- Linear Regression
- Logistic Regression
- Model Training
- Mean Squared Error (MSE)
- Accuracy Evaluation

## What I Learned

In this lab, I learned that regression models are used to predict continuous numerical values, while classification models are used to predict categories or classes. I trained both a Linear Regression model to predict passenger fares and a Logistic Regression model to predict passenger survival. This lab helped me understand how to choose the appropriate model based on the type of problem and how to evaluate model performance using different metrics.
