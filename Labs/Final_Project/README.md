# Final Project – IMDb Movie Review Sentiment Analysis

## Overview

For my final project, I developed an end-to-end **sentiment analysis** system using the IMDb Movie Reviews dataset. The objective was to build machine learning models capable of classifying movie reviews as either **positive** or **negative** while following the complete machine learning workflow from data exploration to business recommendations.

## Objectives

- Define a real-world business problem
- Explore and analyze text data using Exploratory Data Analysis (EDA)
- Clean and preprocess text reviews
- Convert text into numerical features using TF-IDF
- Train and compare multiple machine learning models
- Evaluate model performance using several evaluation metrics
- Interpret results and provide business insights

## Project Summary

The project began with exploratory data analysis to better understand the dataset, including class balance, review lengths, and common words. After preprocessing the review text, I converted the data into TF-IDF features and trained three machine learning models: Logistic Regression, Multinomial Naive Bayes, and Random Forest.

Each model was evaluated using accuracy, precision, recall, F1-score, classification reports, and confusion matrices. I also compared model performance, analyzed misclassified reviews, discussed the limitations of the models, and provided recommendations for future improvements.

## Results

- **Logistic Regression:** **85.6% Accuracy** (Best Performing Model)
- **Multinomial Naive Bayes:** **84.3% Accuracy**
- **Random Forest:** **81.2% Accuracy**

Logistic Regression achieved the highest overall performance and was selected as the recommended model for deployment due to its balanced accuracy, precision, recall, and F1-score.
