# Module 04

## Overview

This lab focused on **Exploratory Data Analysis (EDA)** using the Titanic dataset. The goal was to understand the data before building machine learning models by using summary statistics and visualizations to identify patterns, relationships, and potential issues.

## Objectives

- Learn the purpose of Exploratory Data Analysis (EDA)
- Explore the Titanic dataset
- Calculate descriptive statistics
- Create visualizations to identify trends and relationships
- Interpret findings before modeling

## Skills Practiced

- Python
- Pandas
- Matplotlib
- Seaborn
- Exploratory Data Analysis (EDA)
- Data Visualization

## What I Learned

In this lab, I learned how important exploratory data analysis is in the machine learning process. I practiced using summary statistics and visualizations to better understand a dataset before training a model. By analyzing the Titanic dataset, I identified patterns such as the relationship between survival and passenger class, gender, and age, demonstrating how EDA can provide valuable insights that guide future modeling decisions.
