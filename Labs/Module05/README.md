# Module 05

## Overview

This lab focused on **data preparation and preprocessing**, one of the most important stages of the machine learning workflow. Using the Titanic dataset, I practiced handling missing values, encoding categorical variables, and scaling numerical features to prepare the data for machine learning models.

## Objectives

- Handle missing values using imputation
- Encode categorical features with One-Hot Encoding
- Scale numerical features using StandardScaler
- Prepare a dataset for machine learning

## Skills Practiced

- Python
- Pandas
- Scikit-learn
- Data Preprocessing
- Missing Value Imputation
- One-Hot Encoding
- Feature Scaling

## What I Learned

In this lab, I learned that raw data usually needs to be cleaned before it can be used for machine learning. I practiced filling in missing values with the median, converting categorical variables into numerical features using One-Hot Encoding, and standardizing numerical features with StandardScaler. These preprocessing techniques are essential for improving model performance and ensuring data is ready for analysis.
